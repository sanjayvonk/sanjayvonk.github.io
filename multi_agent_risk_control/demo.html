3‑Way Comparison: No risk control vs Global risk control vs Selective worst‑channel control

Three simulations run in parallel with the same pedestrians. Drones have inertia and plan a short‑horizon path using constant‑velocity prediction. The global controller updates a single scalar using the realized worst‑channel loss and applies it to all channels; the proposed controller updates the same scalar but applies it only to the previous/current worst channel, while other channels keep local parameters.
